All Kashmiri text uses one Unicode convention (NFC with the Kashmiri letters ٲ ؠ ۄ ۍ ێ and vowel signs ٕ ٔ ٟ ٖ ٗ ٚ ٛ). Details, data files and code: github.com/rizvonium/kashmiri_dictionary.

How the any-spelling search works

Every Roman spelling is reduced to a sound key (cxoont, tsoont, tsūnṭh → tsunt) and a consonant root (koshur, kaeshur → kshr). Kashmiri script is matched with or without vowel signs, and common letter variants (ٲ/ا, ؠ/ی, ۄ/و) are treated alike. In the writer, when a word has several dictionary spellings, the one whose meaning fits the neighbouring words best is chosen; tap a word to see the alternatives.
