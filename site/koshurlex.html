Online Sources with Romanized Kashmiri

This page already loads the merged dataset (Grierson 1932, Hassan, Kaeshir, kashmirizabaan, ChiKhaPo — 46,872 entries) plus ~39,000 Roman spellings from Aksharantar. These are the upstream sources and other candidates, with what we found when checking them:

1. Kaeshir Dictionary Data (28,718 words — MIT) ✓ included
Repo: github.com/izan-majeed/kaeshir-dictionary-data · Python: pip install kashmiri
collected-words.json (5,156): kashmiriMeaning = Kashmiri Unicode, englishMeaning = Romanized Kashmiri, title = English. audio-words.json (2,919, Hassan) and dictionary-words.json (20,643, Grierson): word = Romanized Kashmiri, desc/meaning = English.
2. Grierson 1932 & Hassan via DSAL (University of Chicago) ✓ included
dsal.uchicago.edu/dictionaries/grierson · dsal.uchicago.edu/dictionaries/hassan
Grierson: romanized headwords + Devanagari for nearly all entries, Perso-Arabic only for ~17% (loanwords). Hassan: phonemic romanization + audio; its Perso-Arabic is machine-generated.
3. AI4Bharat Aksharantar — Kashmiri transliteration pairs ✓ included (spellings)
huggingface.co/datasets/ai4bharat/Aksharantar → kas.zip (openly downloadable)
57,999 word pairs, no meanings: native word → Kashmiri Unicode, english word → Romanized Kashmiri. We keep the AK-Freq, AK-Uni and IndicCorp parts (~41,000 words) and drop the named-entity lists (foreign personal and place names). Used to recognise everyday Roman spellings.
4. ChiKhaPo Kashmiri–English lexicon ✓ included (flagged unverified)
huggingface.co/datasets/ec5ug/chikhapo → data/kas_eng.jsonl (MIT)
7,915 Kashmiri → English pairs (4,615 Perso-Arabic, 3,292 Devanagari). Automatically compiled, so some entries are noisy.
5. Checked but not used
Omarrran multilingual dictionary is gated (manual approval required). KATHE restorer ships model weights only; its companion lexicon is 10,703 diacritization mappings with no meanings. Shafi Shauq’s Kāśir Lug̲h̲at is copyrighted (look-up only on DSAL). Indic educational glossary: its Kashmiri column is empty in all 6,870 rows. PanLex (CC0): 7,776 Kashmiri expressions, mostly Devanagari/Roman; pairing them with English needs a 786 MB file — a candidate for later.
