# Source assessment: which Kashmiri dictionary sources are usable

All sources were checked on 2026-11-02 by downloading them and reading the
files, not just the descriptions. Several things the descriptions claimed did
not match what the files actually contain. Those cases are marked ⚠.

## License summary for the merged dataset

Each row has a `license` field that carries the licence of every source it came
from. In practice:

* **Safe to redistribute:** `kaeshir` (MIT), `chikhapo` (MIT) and the
  Aksharantar spellings (CC-BY / CC0; credit AI4Bharat).
* **Non-commercial only:** `grierson`. The 1932 text is public domain, but we
  took it from DSAL's digital edition, which is licensed CC BY-NC-ND 2.0
  (credit DSAL, non-commercial, no derivatives). Re-keying from a scan of the
  1932 print would avoid this restriction.
* **Use with care:** `kashmirizabaan`. The scraper is MIT, but the rights to
  the content on the original site are unclear. `hassan` states no licence (© Sheeba Hassan / SALRC, University of
  Chicago), so treat it as all rights reserved: research use only, and ask
  before redistributing.
  `injilashah-phonemes` has no stated licence.

To publish a dataset that is clean for commercial use, filter on
`source ∈ {kaeshir, chikhapo}` (plus the Aksharantar spellings).
